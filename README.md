# Infraseal

Technical notes, project writeups, and field observations from cloud engineering, infrastructure reviews, monitoring, cost management, security, and AI workload governance.

This repository powers the GitHub Pages site for the blog. The goal is simple: document practical engineering lessons in a way that is useful to clients, engineers, and anyone trying to make sense of real environments.

## Local Preview

This is a Jekyll site using the `minima` theme.

```bash
bundle exec jekyll serve
```

If the GitHub Pages gems are not installed locally, the site can still be edited as Markdown and rendered by GitHub Pages after push.

## Structure

- `index.md` - site homepage
- `docs.md` - topical index for useful notes
- `about.md` - short site overview
- `_posts/` - blog posts
- `assets/main.scss` - light theme customizations
